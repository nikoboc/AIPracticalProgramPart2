## このパートの位置づけ

ワークフロー作成の開始回。制作課題は**「ミニチュア版 ChatGPT（なんちゃって ChatGPT）」**。作り始める前に、n8n で作るワークフローの2分類（AIオートメーション／AIエージェント）を整理し、その後トリガーと AI Agent ノードを配置して、**あえてエラーを出す**ところまでを扱う。

## 説明している内容

### n8n のワークフローは大きく2種類に分類できる

#### ① AIオートメーション

- **一方向の処理フロー**が特徴。**順次処理型・線形構造**とも呼ばれる。
- 「A が起きたら B をする、B が起きたら C をする、C が起きたら D をする」というように、**あらかじめ決められた動きしかできない**ワークフロー。
- 最初のインプットから最後のアウトプットまで、**常に同じ動き**をする一方向の処理に特化した構成。
- 仕事の場面で言えば**定型業務**（毎回同じ業務処理が行われるもの）がイメージしやすい。

#### ② AIエージェント

- **動的判断と並列処理**が特徴。
- AIオートメーションとの最大の違いは、**AI自身が動的な判断をできる**こと。あらかじめ決められた動きではなく、ユーザーのインプットから**AIエージェント自身がどう動くべきかを判断**する。
- 例えとして**「優秀な秘書」**を挙げる。
  - 「◯◯さんにメールを送っておいて」と依頼すると、秘書は
    1. ◯◯さんの連絡先を探す
    2. メールの本文・件名を作成する
    3. メールを送信する
  - というように、**与えられた目的（ゴール）を達成するために、自分が持っているツールの中からどれをどんな順番で使うべきかを自分で判断し、実行する。**
- この**動的な判断**こそが両者の一番の違いであり、講座を通してマスターする核心部分。

> 今回作る「なんちゃって ChatGPT」は **AIエージェント**に分類される。

> 【追記】n8n 公式ドキュメントも同じ整理をしている。「作業が固定的すぎず、リクエストを解釈して適切なツールを選ぶ必要がある場合にエージェントを使う」という基準。

### トリガーとは

- **ワークフローを開始させるためのきっかけ**のこと。
- 身近な例：メールの送信ボタン、SNS の投稿ボタン。
- **どのワークフローにも絶対に必要不可欠**な存在。
- 【追記】現行の n8n では、トリガーの種類によって **Publish が必要かどうかが変わる**（②参照）。
  - Webhook・スケジュール・フォームなどのトリガー → 自動で動かすには **Publish が必須**
  - Chat Trigger でキャンバスからテストするだけ → **Publish は不要**

## 画面操作の手順

### 1. トリガーを追加する

1. キャンバス画面中央の**「Add first step...」**をクリック。
2. 右側にトリガーのメニューが表示される。
3. 今回は「ユーザーがチャットでメッセージを送信したこと」をトリガーにしたいので、**`Chat Trigger`**（検索欄に `chat` と入力）を選択。
4. **「Back to canvas」**、または設定パネルの枠外をクリックして閉じる。→ キャンバス上にトリガーが追加される。
5. **保存操作は不要**（自動保存）。

> 【補足】Chat Trigger には **Hosted Chat**（n8n が用意するチャット画面を使う／推奨）と **Embedded Chat**（自前の画面から Webhook URL を叩く）の2モードがある。講座では既定の Hosted Chat を使う。

### 2. AI Agent ノードを追加する

1. 追加されたトリガーの右の**＋ボタン**をクリック。
2. **AI → AI Agent** ノードを選択して追加。
3. 「Back to canvas」または枠外をクリックして閉じる。
   → ユーザーからのチャットメッセージを受け取る AI を設置できた状態。

> 【追記】動画の時代にあった **Agent type（Tools Agent / Conversational Agent / ReAct Agent など）の選択肢は表示されない。** n8n 1.82.0 以降、AI Agent ノードはすべて **Tools Agent** として動作する。古い解説記事で「Tools Agent を選んでください」と書かれていても、現行では選ぶ画面自体が存在しない。
>
> 古いテンプレートを読み込むと Agent type 設定を持つ **v1 の AI Agent ノード**が入っていることがある。**v1 は n8n 3.0 で削除される予定**なので、見つけたら最新版のノードに差し替えておく。

### 3. テスト実行してエラーを確認する

1. 画面下の**チャット欄**を開いてメッセージを入力する。
2. 例：**`こんにちは`** と送信。
3. → **エラーが出る。**

## 動画中の入力例・設定値（現行版）

| 項目 | 値 |
|---|---|
| トリガーノード | `Chat Trigger` |
| 追加ノード | `AI Agent` |
| チャット入力 | `こんにちは` |
| 保存操作 | 不要（自動保存） |

## エラーの説明（このパートの締め）

- AI Agent ノードは追加できたが、応答せずエラーになる。
- 理由：**「こんにちは」を受け取っても、AIエージェント自身がまだ考えることができない。**「AIの脳みそ」＝ Chat Model がまだ接続されていない状態だから。
- 次のパート（④）で、AIエージェントに考える力を与える。

> 【追記】n8n 公式ドキュメントでは、AI Agent ノードは **Chat Model に加えてツールを最低1つ接続する必要がある**と明記されている。ただし講座の流れ上、ツールは⑥で追加するため、④〜⑤の段階でツール未接続の警告が出ることがある。**警告が出ても④⑤のテスト実行自体は通る**ので、そのまま進めてよい。

## 講師が強調している点（現行版）

- AIオートメーション（順次処理型・決められた動き）と AIエージェント（動的な判断）の**2種類がある**ことをまず押さえる。
- 動的判断がこの講座の核心。
- トリガーはどのワークフローにも必要不可欠。
- ~~編集を加えたら都度 Save~~ → **編集は自動保存される。本番に出すときだけ Publish**（②から継続）。
