# 07 — APIとHTTPリクエスト

`00:20:42 / 座学＋画面操作`

> 既存動画の説明内容を文字起こしに基づいて整理したもの。現行サービス仕様との不一致は本ドキュメントでは補正していない。

## このパートの位置づけ

AIエージェントの能力を**文字通り無限に広げる鍵**として、API と HTTP Request ノードを扱う。n8n に専用ツールがないサービス（社内システム、最新のAIサービスなど）と連携する方法を、**Tavily**（Webリサーチツール）を練習題として習得する。

## 説明している内容

### 専用ツールの限界

- これまで使ってきた Gmail・Wikipedia は、**n8n 側があらかじめ用意してくれているブロック（ノード）**。
- しかし世の中には専用ツールが用意されていないサービスが山ほどある。
  - 特定の業界の業務システム
  - 出たばかりの最新のAIサービス
  - 社内で使っている独自のツール
- **そうしたあらゆるサービスと接続するために使うのが HTTP Request ノード。**「専用ツールがないから n8n は使えない」と諦める必要は一切ない。

### API とは

- **Application Programming Interface** の略。難しく考えなくてよい。
- 言ってしまえば、**普通ならつながらないアプリケーション A と B を連携させるもの**。
- **レストランの例え**：
  - お客様（クライアント）／キッチン（サーバー）／**ウェイター＝API**
  - お客様が注文をウェイターに伝える → ウェイターがキッチンに伝えて料理を受け取る → ウェイターがお客様に料理を提供する
  - ＝ お客様のリクエストをキッチンに伝え、処理してレスポンスを返す流れ。
- つまり **プログラム同士が接続するためのルール**のこと。
- ④で使った **API キー**は、そのルールにおける**会員証・身分証明書**のようなもの。「このサービスにきちんとお金を払っている正規のユーザーです」と証明するための大事な鍵。

### HTTP Request ノードとは

- 外部サービスの API と接続するための**自由度の高いノード**。内容の仕組みを自分で作れる。
- 専用ツールには n8n と接続するための設定がすでに入っているが、**HTTP Request ノードではその設定を自分で書く必要がある**。
- 講師の比喩：**「白紙の注文伝票」**。

### GET と POST

| メソッド | 意味 |
|---|---|
| **GET** | データの取得 |
| **POST** | データの送信・作成 |

→ 今回の Tavily はデータを作って送信するので **POST**。

### cURL とは

- 小文字の c ＋ 大文字の URL で **cURL**。
- **API を接続するための設定内容が書かれたコードのようなもの。**
- これをコピーできれば、**専門知識がなくても、注文に必要な情報が一気に手に入る**。
- 開発者向けドキュメントは全部英語で難しそうに見えるが、**僕たちが探すべきものはたった一つ、cURL だけ**。

### cURL の構成（Tavily のサンプルを見ながら解説）

| 部分 | 意味 |
|---|---|
| `POST` | リクエストの内容。何かをお願いするものか、受け取るものか |
| `https://...`（URL） | 接続先のリンク。リクエストを送る宛先 |
| ヘッダー部分 | 補足情報。「自分の会員証はこれです」＝ API キーを載せる |
| `-d` の部分 | 具体的なリクエスト内容。Tavily に何を調べてほしいかという具体的なお願い（プロンプトのようなもの） |

## 画面操作の手順

### 1. Tavily のアカウント作成と API キー取得

1. Google で `Tavily` を検索してサイトを開く。
   - Tavily とは：一言で言うと **AI によって強化された Google**。AI が検索をかけ、インターネットの情報を賢く調べてまとめてくれるサービス。
   - **毎月 1000 クレジットまで無料**（クレジット制）。
2. 右上の **Sign up** からログイン（Google ログイン等。手順は OpenRouter とほぼ同じ）。
3. サイト上の **API キー**の欄の**＋**から新規作成。
   - **Key Name**：動画では **`n8nデモ`**。
4. **Create** を押す。
5. 発行されたキーは隠されているので、**表示させてコピー**（コピーボタン、または四角のアイコン）。大事に保管する。

### 2. Tavily のドキュメントから cURL を取得

1. Tavily サイトの左側の **Documentation** を開く。
2. **Quickstart** を開き、下へスクロール。
3. Python / JavaScript / **cURL** のタブがあるので **cURL** を選択。
4. コードが表示されるので、**右上のコピーボタン**でコピー。

### 3. n8n に cURL をインポートする

1. キャンバスの**＋**から `HTTP Request` を検索して追加（動画では検索結果の**下の部分**を使用）。
2. HTTP Request ノードを開くと **「Import cURL」** がある。
3. **「Paste the cURL command here」**の欄に、コピーした cURL をペースト。
4. **Import** を押す。
   → **設定が一気にすべて入力される。**（講師の表現：「難解な呪文みたいなものが自動で伝票に書かれたみたいな感じ」）

### 4. API キーとプロンプトを埋める

1. **Header の Value** を確認すると `Tavily ... Your API Key` のようになっているので、**`Your API Key` の部分を、Tavily で取得した API キーに置き換える**。
   - 前の部分（`Bearer` に相当する語）は**残して半角スペースを空け、その後に API キーを入力**する。
2. **Body** を確認すると、サンプルのクエリ（動画では「メッシは誰ですか」のような内容）が入っているので、ここにプロンプトを書く。
   - 動画では **`今日のAIニュースについて詳しく教えて`**。
   - ⚠️ **ダブルクォーテーション（" "）で囲むのを忘れずに。** 忘れがちなポイント。

### 5. ノード単体でテスト実行

1. HTTP Request ノードを**単体で1回実行**する。
2. **Output** に Tavily が調べてくれた結果が返ってきたら成功。
   - 動画では「今日のAIニュース」として、ChatGPT のモデルの性能比較などが一気に出てきた。

### 6. チャット入力と連動させる

- 直接書いていた「今日のAIニュースについて詳しく教えて」を、**チャットで書いたものを反映させる**ように変更する。
- Body の `query` に **`{{ $json.chatInput }}`**（チャットで書いたものをここに反映させる設定）を指定する。
- チャットから **`今日のAIニュースについて教えて`** と送ると、調べた内容がチャット上に返ってくる。
  - 動画での返答例：「本日最新の具体的なAIニュースの情報は厳しい情報ですが、最近注目されているAIの話題としては以下のものです」として詳細が出力された。

## エラーが出たときの対処（フレームワークの先出し）

エラーが出たら、**ChatGPT や Google AI Studio（Gemini）の出番**。

1. ノードの下部（アウトプットのエラー部分）を押すと、**エラーの理由が詳しく出る**。
2. その**エラーコードをコピー**。
3. **画面右上からワークフロー全体の JSON コードをダウンロード**。
4. ダウンロードしたファイルを ChatGPT や Google AI Studio に**アップロード**。
5. 「◯◯というところでエラーになっています。これを修正したいです」と伝える。
6. → AI がトラブルシューティングをしてくれる。

> **エラーが出たらまず AI に聞いてみる、を習慣づけること。**

## 動画中の入力例・設定値

| 項目 | 動画での値 |

| 追加ノード | `HTTP Request` |

## 講師が強調している点

- 外部サービスと連携する際の手順は2点だけ：**① ドキュメントを見つける ② cURL を見つける**。
- API キーは会員証・身分証明書。
- ダブルクォーテーションで囲むのを忘れない。
- 専用ノードがなくても諦める必要はない。**AIエージェントの可能性は文字通り無限大に広がる。**
- **API・HTTP リクエスト・cURL** の3つをしっかり覚えること。

## 備考

- Tavily の「毎月 1000 クレジット無料」は**動画収録時点の条件**。
- ヘッダーの書き方（`Bearer` の扱い）は、動画では画面を指しながらの説明のため、文字起こしからは正確な文字列が確定できない。
- チャット連動の式は、文字起こし上は「クエリ、JSONのチャットインプット」という口頭説明のみ。上記 `{{ $json.chatInput }}` はその表記に対応させたもので、画面の入力文字列そのものではない。
