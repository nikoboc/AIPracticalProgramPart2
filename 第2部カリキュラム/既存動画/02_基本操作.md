# 02 — 基本操作

`00:09:25 / 画面操作`

## このパートの位置づけ

n8n の基本操作を覚えながらAIエージェントの基本的な仕組みを理解し、自分のアイデアを形にするための考え方を身につける導入パート。アカウント作成 → 管理画面（ダッシュボード）の機能紹介 → キャンバス画面の基本操作、までを扱う。

## 画面操作の手順

### 1. アカウントの作成

1. 「n8n」で検索し、n8n 公式ホームページを開く。
2. 画面右上の**オレンジのボタン「Get started」**をクリック。
3. 名前・メールアドレス・パスワードを入力し、**青いボタン「Start free」**を押す。
4. 作成が完了すると**ダッシュボード（管理画面）**が表示される。

> 動画内の補足：n8n には **14日間の無料トライアル期間**があるので活用してほしい。

### 2. ダッシュボード（管理画面）の主要機能

| メニュー | 場所 | 説明 |
|---|---|---|
| **Workflows** | 画面左上 | 自分が作成していく自動化の仕組み（＝ワークフロー）が一覧表示される。作成中・過去作成分を一元管理する画面 |
| **Credentials** | Workflows の右隣 | 外部サービスと連携する際に必要な**認証情報**を管理する画面。Googleスプレッドシート、Googleカレンダー、Gmail、Slack、OpenAI（ChatGPT）などとの連携に必要。詳細は④で扱う |
| **Executions** | 〃 | 作成したワークフローが**いつ・どのように動いたか**の履歴（ログ）が一覧記録される画面。赤＝エラー（途中で止まった）、緑＝Success（正常実行）。どこで・いつ・どんなエラーが起きたかを確認する重要機能 |
| **Data Tables** | 〃 | **ベータ版（動画時点で本格実装前）**。n8n のクラウド上にデータを保存できる、Excel／スプレッドシートのような機能 |
| **Templates** | 画面左側メニュー | 世界中の n8n ユーザーが作成したワークフローのテンプレート一覧 |

#### Data Tables の説明（動画内の言い回し）

- 本来はデータを扱う際、外部のデータベース（自分のスプレッドシートや Excel）との連携が基本的に必要になる。
- 簡単なデータであれば n8n の中でデータを保存・管理できるようになったもの、というイメージ。
- 現状ベータ版だが、本格実装された際にはぜひ活用してほしい。

#### Templates の説明

- 現在 **6700 ちょっと**のテンプレートが公開されており、日々増え続けている。
- 実際のワークフロー画面とワークフローの説明が記載されている。
- 自分でワークフローを作成する際に、**既存テンプレートからアイデアを持ってくる／自分が作りたいものに近いものを参考にする**という使い方を推奨。今後のワークショップでも活用する。

### 3. 最初のワークフローを作る（キャンバス画面）

1. ダッシュボード右上の**「Create Workflow」**ボタンを押す。
2. **キャンバス画面**が開く。この画面上で実際のワークフローを作成していく。
3. 画面左上のワークフロー名（動画では **`My Workflow 92`**）をクリックすると、任意の名前に変更できる。
   - 動画では **`デモ`** という名前に変更して OK。
4. 画面右上の**オレンジのボタン「Save」**で保存する。

## 動画中の入力例・設定値

| 項目 | 動画での値 |
|---|---|
| ワークフロー名 | `My Workflow 92` → `デモ` に変更 |

## 講師が強調している点

- **n8n には自動保存機能がない。** Excel やスプレッドシートと違い、変更・編集を加えても自動では保存されないため、**変更のたびに「Save」ボタンを押す癖をつける**こと。動画中でも「非常に重要な機能」として繰り返し強調している。
- Workflows / Credentials / Executions / Data Tables / Templates の5つは覚えておくこと。
- Executions は「ちゃんと動いているか」「エラーならどこで・いつ・どんなエラーか」を確認する重要機能。
