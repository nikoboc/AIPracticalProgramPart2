# 04 — Credential（認証情報）

`00:12:01 / 画面操作`

> 既存動画の説明内容を文字起こしに基づいて整理したもの。現行サービス仕様との不一致は本ドキュメントでは補正していない。

## このパートの位置づけ

③で作った「骨組みだけで頭脳がない」AIエージェントに、外部の LLM を接続して**考える力（頭脳）**を与える。そのために必要な **Credential（認証情報）** の概念と、OpenRouter の API キー取得〜n8n への登録を扱う。

## 説明している内容

### Credential（認証情報）とは

- n8n 自身が、Gmail・Slack・LLM（AI）などとつなげるために必要な**パスワード／認証情報**のこと。

### なぜ OpenRouter を使うのか

- ChatGPT・Claude・Gemini など様々な LLM があるが、**一つの認証情報で手軽に複数のモデルを利用できる**のが OpenRouter。
- ChatGPT や Gemini を直接使う場合も**設定方法は同様**なので、参考になる。

### コストの考え方

- LLM（AIの頭脳）を使うには**コストがかかる**。イメージは**電気代**。自動化ワークフローを動かすための電気代のようなもの。
- 一般的には**1回の実行で1円かかるかかからないか**程度だが、**ゼロではない**点に注意。
- 金額は**トークン**という単位で計算する。ざっくり**1文字＝1トークン**と思ってよい。
- 対話が多い・実行が多い・処理が多いほど料金がかかる、というシンプルな仕組み。

### OpenRouter はデポジット制

- Suica や PASMO と同様、**あらかじめ OpenRouter 側にクレジットをチャージ**しておき、使用するごとに減っていく方式。
- そのまま OpenRouter を使う場合はクレジットのチャージが必要。

### n8n からの無料プレゼント（動画内の案内）

- **OpenAI Chat Model** を使う場合、**n8n から最初に 100 クレジット分が無料でプレゼント**される。
- Chat Model 追加時に紫色になっている部分を押すと受け取れる。
- 「まず無料枠で試したい」人は OpenAI Chat Model を追加するとよい（動画本編は OpenRouter で進行）。

## 画面操作の手順

### 1. OpenRouter で API キーを発行する

1. OpenRouter のサイトを開く。
2. 画面右上の**「Sign up」**からアカウントを作成（Google／Gmail アカウント、またはメールアドレス＋パスワード）。
3. ログイン後、右上のメニューの**上から2番目「Keys」**をクリック。
4. API キーの画面が開くので、紫色の**「Create API key」**をクリック。
5. 設定項目
   - **Name**：発行する API キーの名前。動画では **`n8nデモ`**。
   - **Credit limit（上限）**：どれくらい API を使用してよいかの上限。任意設定。動画では**設定せずに進行**。
6. **「Create」**をクリック → 「Your New Key」画面で新しいキーが発行される。
7. 右側のコピーボタンでコピーし、メモや他のツールにペーストして保管する。
8. ×印を押して画面を閉じる。

> ⚠️ **API キーの取り扱い**：連携に必要なパスワードのようなもの。**他の人に絶対に教えないこと。** 講師は「クレジットカード情報と同じくらい機密性が高い」と表現し、「私もこの後すぐ削除します」と明言している。

### 2. n8n 側で Chat Model を接続する

1. n8n のキャンバス画面に戻る。
2. **AI Agent ノードの左側にぶら下がっている「Chat Model」の＋ボタン**をクリック。
3. 接続できる Chat Model の一覧が表示されるので、**`OpenRouter Chat Model`** を選択。
4. **「Create New Credential」**ボタンを押す。
5. **API Key** の欄に、先ほどコピーした OpenRouter の API キーを**ペースト**。
6. **Save** を押す。
7. 認証が完了すると**緑色の表示**になる。→ 連携 OK。

### 3. 動作確認

1. 再度 **Save** を押す。
2. チャットから **`こんにちは`** と送信。
3. → **「こんにちは、ご用件は何でしょうか」**といった返答が返ってくる。「なんちゃって ChatGPT」がひとまず動作する状態になった。

### 4. ログの確認

- 画面下のメニューの**「Logs」**で、実際の動き（実行履歴）を確認できる。
- 接続した OpenAI／OpenRouter で**消費したトークン数**もここで確認できる。どのくらいコストがかかったかを見られる。

## 動画中の入力例・設定値

| 項目 | 動画での値 |
|---|---|
| API キー名（OpenRouter） | `n8nデモ` |
| Credit limit | 設定しない |
| Chat Model ノード | `OpenRouter Chat Model` |
| チャット入力 | `こんにちは` |

## 講師が強調している点

- API キーは**絶対に他人に教えない**。
- コストは**ゼロではない**。トークン＝おおよそ文字数で課金される。
- OpenRouter は**事前チャージ（デポジット）制**。
- Logs でトークン消費量を確認する習慣。
