# 05 — メモリとシステムメッセージ

`00:08:12 / 画面操作`

> 既存動画の説明内容を文字起こしに基づいて整理したもの。現行サービス仕様との不一致は本ドキュメントでは補正していない。

## このパートの位置づけ

④で会話できるようになったAIエージェントの欠点（記憶がない）を実演で体験させ、**Memory** を追加する。続いて、AIエージェント開発で最重要と位置づける**システムメッセージ**を扱う。

## 前半：メモリ

### 欠点の実演

1. チャットに **`私の名前は田中です。`** と送信 → **「田中さん、こんにちは」**と返ってくる。
2. 続けて **`私の名前は何ですか？`** と質問 → **「ごめんなさい、名前についての情報を持っていません」**と返る。

→ **直前の会話すら覚えていない。** AIエージェントにまだ「記憶」の機能がないため。

> 講師の補足：ChatGPT は過去の会話の記録を踏まえて回答してくれる／覚えてくれる機能を備えているが、このAIエージェントにはまだない。

### 画面操作の手順（Memory の追加）

1. **AI Agent ノードの真ん中にぶら下がっている「Memory」の＋ボタン**を押す。
2. メモリは任意のものを指定できるが、今回は **`Simple Memory`** を選択。
3. 設定画面の重要項目：**Context Window（コンテキストウィンドウ）**
   - デフォルトは **`5`**。
   - 意味は「**過去何回分の会話を記憶しますか**」という設定。
   - `10` に増やす、`3` に減らすなど、任意で変更できる。
4. 動画ではデフォルトの **5 のまま**進行し、キャンバス画面に戻る。

### 動作確認

1. 再度 **`私の名前は田中です。`** を送信 → 同様の返答。ただし**Memory のところにチェックがつき、実行されたことが確認できる**。
2. **`私の名前は何ですか？`** → **「あなたの名前は田中さんです。よろしくお願いします」**と返る。→ 記憶機能が追加できた。

### 押さえるポイント

- 作成するワークフローの目的に応じて、
  - そもそも**記憶機能をつけるのか／つけないのか**
  - つけるなら**どれくらい会話を記憶させたいのか**

  を設定する必要がある。

## 後半：システムメッセージ

### システムメッセージとは

- **AIに与える行動指針・役割設定**のこと。
- AIエージェントがユーザーと会話する際に、**どういった役割で／どういった立場で回答したらいいか**という「マニュアルのようなもの」を設定できる。
- 講師の位置づけ：**メモリ機能よりももっと強力で、さらに重要な機能。AIエージェント（オートメーションではなく）の開発において最も重要と言っても過言ではない。**

### 画面操作の手順

1. **AI Agent ノード**を開く。
2. 下部の**「Add Option」**を選択 → 一番上に**「System Message」**が表示される。
3. これを押すとシステムメッセージの入力欄が追加される。
4. 動画では **`関西弁で回答してください`** と入力。
5. **Save** を押して実行。

### 動作確認

- 質問すると**コテコテの関西弁**で回答が返ってくる（「大きいな」「あいの状態めっちゃええで」等）。
- それまでの回答と**口調が明確に変わった**ことを確認する。

### 押さえるポイント

- システムメッセージを使うと、**応答のスタイルだけでなく、指示の処理方法まで AI をコントロール・制御できる**。
- 重要な理由：**今後さまざまなツールをAIエージェントに追加していくにあたり、システムメッセージが「与えられたツールの使い方」を制御するために必要不可欠**になるから。

### 補足：英語で書くほうが精度が高い

- 今回は「関西弁で」と日本語で指示したが、**AIは英語の指示のほうが精度の高い回答を出してくれる**。
- 理由：LLM にとって**日本語の情報より英語の情報のほうが世の中に多い**ため。
- **より高精度な指示・複雑な指示を与えたい場合は、システムメッセージを英語で設定するのが現時点では非常に有効。**

## 動画中の入力例・設定値

| 項目 | 動画での値 |
|---|---|
| Memory ノード | `Simple Memory` |
| Context Window | `5`（デフォルトのまま） |
| System Message | `関西弁で回答してください` |
| チャット入力 | `私の名前は田中です。` / `私の名前は何ですか？` |

## 講師が強調している点

- メモリがない状態を**先に体験させてから**追加する構成になっている。
- システムメッセージは AIエージェント開発の最重要機能。**絶対に覚えること。**
- 複雑な指示は英語で書く。
