# 06 — ツールとオーケストレーション

`00:11:32 / 画面操作`

## このパートの位置づけ

AIエージェントの可能性を劇的に広げる**ツール**という概念を学ぶ。Wikipedia ツールを1つ追加 → 続けて Gmail ツールを追加し、**複数ツールを組み合わせた処理（オーケストレーション）**を体験する。最後に、複数ツールを正しい順番で使わせるための**システムメッセージによる制御**へつなげる。

## 説明している内容

### ツールとは

- 一言で言うと **AIエージェントに与える道具**。
- これまでのAIエージェントは **Chat Model と Memory しか持っていなかった**が、ツールを与えることで **AI に「手足」を授ける**ことができる。
- 具体例：Gmail、Google ドライブ、スプレッドシート、Slack、Notion など様々な外部サービス。
- **AI Agent ノードの一番右**にある「Tool」から追加する。

## 画面操作の手順

### 1. Wikipedia ツールを追加する

1. AI Agent ノードの右側「Tool」の**＋ボタン**を押す。
2. 検索欄で `Wikipedia` を検索し、**Wikipedia ノード**をクリックして追加。
3. チャットで動作確認：**`Wikipediaで織田信長について調べて`** と送信。
4. → AIエージェント自身が Wikipedia ツールを使い、織田信長に関する情報を出力する。
   - ⑤のシステムメッセージ（関西弁）の名残で、**関西弁で返ってくる**。

### 2. Gmail ツールを追加する（＋認証情報の設定）

やること：**Wikipedia で検索した内容を Gmail の下書きに作成する。**

1. ツールの追加ボタンから **Gmail ツール**を追加。
2. 新しく使うツールは **Credential（認証情報）の設定が必要**。**「Create New Credential」**から進める。
3. 認証画面の**「Sign in with Google」**ボタンを押す。
4. 連携する Gmail アカウントを選択。
5. 「許可しますか」の画面で**チェックを入れて許可**する。
6. n8n の画面に戻ると**緑色で「つながりました」の表示**が出る。→ 連携 OK。

> 講師コメント：**Gmail の連携認証は非常に楽**（ボタンひとつで完了する）。

### 3. Gmail ツールの設定（下書き作成）

| 設定項目 | 説明 | 動画での選択 |
|---|---|---|
| **Resource** | Gmail に何を扱わせるか。Message（メール本文に関すること）／Label（仕分け）／Draft（下書き）／Thread | **Draft** |
| **Operation** | 選択したリソースを何するか。Create（作成）／Delete（削除）／Get（既存の下書きの情報を抽出）／Get Many（複数の下書きの情報を抽出） | **Create** |
| **Subject** | 下書き・メールの**件名**。任意入力のほか、`chatInput`（ユーザーが入力したプロンプト）を引っ張ってくることもできる | **キラキラボタン（AI に任せる）** |
| **Email Type** | HTML か Text か | **Text** |
| **Message** | メール**本文**。任意指定も可 | **キラキラボタン（AI に任せる）** |

> **キラキラ（✨）ボタン**：押すと **AI が判断していい感じに件名／本文を作ってくれる**機能。動画ではこれを使用。

### 4. 動作確認

1. チャットで **`Wikipediaで織田信長について調べ、Gmailで下書き作成。`** と指示。
2. 処理が完了したら、連携した Gmail の画面を確認。
3. → **「織田信長についての調査結果」**という下書きがきちんと作成されている。→ 連携完了。

| 項目 | 動画での値 |

| チャット入力② | `Wikipediaで織田信長について調べ、Gmailで下書き作成。` |

## オーケストレーション（このパートの締め）

- 複数のツールをつなぎ合わせることで、AIエージェントの可能性をさらに広げられる。
- **しかし問題がある**：複数のツールがあると、**AIエージェントがユーザーの理想とする使い方（順番）どおりに動かないことがある**。
  - 今回で言えば「**Wikipedia を使ったら Gmail で下書きを作成する**」という順番は守ってほしい。
- **そこで重要になるのが、⑤で学んだシステムメッセージ。**
  - 例：「ユーザーの入力情報についてまず Wikipedia で調べて、調べた内容を要約して Gmail の下書きで作成してほしい」と明記する。
- **複数ツールを扱ううえでは、システムメッセージでAIエージェント自身の動きを制御することが非常に重要なポイント**であり、今後も必ず必要になる設定。
