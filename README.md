## 既存動画と現行仕様の最大の齟齬

**既存動画は「n8n には自動保存がない。変更のたびに Save を押せ」と繰り返し強調しているが、現行の n8n にこの操作は存在しない。**

- n8n 2.4（2026-01-13）で**オートセーブが導入され、Save ボタンは廃止**された。
- 編集はすべて**ドラフト**として自動保存される。**本番反映は `Publish` ボタン**。

その他の齟齬（Gateway credits の追加、Data Tables の正式化、API キーの取り扱い、サブワークフローの Publish 要件など）は
[`第2部カリキュラム/最新仕様反映/README.md`](第2部カリキュラム/最新仕様反映/README.md) に一覧でまとめてある。
